# Knowledge Log Template

## Log Principles

- This file records the update history of the knowledge bundle (OKF `type: changelog`).
- It is appended automatically. Do not rewrite existing entries by hand.
- Each entry records when, which change or review, which knowledge ID, and which operation updated the baseline.
