## Delta Principles

- This document records only the difference against the baseline subsystem spec.
- Do not edit the baseline spec directly. The baseline is updated only by the archive operation.
- Operation maps one-to-one to the requirement ID rule:
  - ADDED: a new requirement ID that does not exist in the baseline.
  - MODIFIED: an existing baseline requirement ID whose content changes; keep the same ID.
  - REMOVED: an existing baseline requirement ID that becomes obsolete; do not delete the ID.
